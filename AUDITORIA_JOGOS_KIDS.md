# Auditoria dos jogos Kids

| Jogo | Joga de verdade | Limite |
| --- | --- | --- |
| Doutor Mirim | Sim: três instrumentos até concluir | Sem animação de estetoscópio |
| Escovação | Sim: cada dente precisa ser tocado | Sem física de creme |
| Alimentação | Sim: três alimentos no prato | Sem arrastar entre widgets |
| Memória | Sim: pares, sem cronômetro | Cartas fecham na hora do erro |
| Quebra-cabeça | Sim: peça só entra no índice certo | Toque, não gesto de arrastar |
| Lavar as mãos | Sim: ordem obrigatória | Sem animação de água |
| Emoções | Sim: escolha + 3 respirações | Sem diagnóstico, de propósito |
| Vacinas | Sim: quatro passos na ordem | Texto marcado para revisão profissional |
| Formas, cores e números | Sim: cor certa por forma | Toque no par correto |
| Sono | Sim: quatro passos da rotina | Sem áudio relaxante |

Não há ranking, anúncio, compra nem punição. Estímulos reduzidos existem como preferência; os jogos não usam luz piscante nem cronômetro.
